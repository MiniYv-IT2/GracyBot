# LLM-Chat 插件

版本：v1.4.2  
开发：GracyBot开发团队

## 功能介绍

LLM-Chat是GracyBot的AI对话插件，支持：
- 多人设切换管理
- 上下文记忆对话
- 智能定时任务
- 戳一戳互动
- 私聊群聊全支持

## 使用说明

### 基础对话
- `//+内容` - 触发AI对话
- 私聊直接发送消息即可对话
- 群聊可@机器人触发

### 主人专属命令

#### API配置（仅私聊）
- `/设置OpenAI API_KEY 模型 地址` - 配置API

#### 人设管理
- `/新增人设 名称 内容` - 添加人设
- `/删除人设 名称` - 删除人设
- `/查看人设列表` - 查看所有人设
- `/切换人设 名称` - 切换当前人设
- `/清除记忆` - 清空对话历史

#### 配置管理
- `/设置上下文数量 数量` - 设置记忆条数
- `/查看配置` - 查看当前配置

#### 戳一戳功能
- `/戳一戳开关 开启/关闭` - 控制戳一戳
- `/戳一戳状态` - 查看状态

#### 英文指令
- `/persona 名称` - 切换人设
- `/+persona 名称 内容` - 新增人设
- `/-persona 名称` - 删除人设
- `/persona=` - 查看人设列表

### 定时任务

支持自然语言设置定时任务，例如：
- "明天早上8点提醒我开会"
- "晚上9点说晚安"

AI会自动识别时间并创建任务。
