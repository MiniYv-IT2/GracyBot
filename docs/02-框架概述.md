## 框架定位

GracyBot 是一个**跨平台 IM 轻量异步框架**，并非专门的 QQ 机器人框架。其核心是**适配器层 + 管道调度器 + 插件体系**的三层架构，只要接入对应平台的适配器，可运行于任何 IM 平台（QQ / Discord / Telegram / 飞书等）。

> 当前内置适配器：OneBot 11 协议（HTTP 回调 + WebSocket 正反向）。
> 其他平台适配器可通过 `gracy_adapter/` 实现。

## 核心特性

| 特性 | 说明 |
|---|---|
| **跨平台** | 同一套插件代码运行于 Windows / Linux / macOS |
| **多实例多账号** | 单进程支持多个 QQ 号同时在线，各账号独立配置、独立路由、独立处理 |
| **适配器架构** | `GracyAdapter` 抽象层解耦协议，切换平台只需更换适配器 |
| **管道调度** | Pipeline 洋葱模型：安全过滤 → 命令匹配 → 插件执行 → 兜底回复 |
| **双风格** | 新风格装饰器（`@on_command` + `@plugin_handler`）与旧风格 7 参数兼容并存 |
| **热重载** | 插件可动态加载/卸载，无需重启框架 |
| **CLI 工具** | 内置 `gracy` 命令行，支持启动/停止/状态/实例管理/插件管理等 |
| **安全审计** | 频率限制、黑名单、敏感信息脱敏、审计日志 |
| **装饰器体系** | `@require_permission` / `@rate_limit` / `@cooldown` 声明式控制 |
| **会话管理** | 内置 `GracySession`，支持对话上下文持久化 |
| **Web 面板** | 内置 GracyUI 管理面板（支持 `--no-webui` 关闭） |

## 消息流概述

一条消息从入站到回复的完整路径：

```
IM平台
  │
  ▼
GracyAdapter（解析为 GracyEvent）
  │
  ▼
EventBus（异步发布）
  │
  ▼
[按 self_id 路由到对应适配器实例]   ← 多账号支持
  │
  ▼
Pipeline（4 个 Stage 顺序执行）
  │
  ├─ Stage 1: SecurityFilter
  │   ├── 黑名单检查
  │   ├── 审计日志记录
  │   └── 监控统计
  │
  ├─ Stage 2: BuiltinCommands
  │   └── /关机 /重启 /开机 /关于
  │
  ├─ Stage 3: CommandMatcher
  │   ├── TOML commands 匹配
  │   └── @on_command 装饰器匹配
  │
  ├─ Stage 4: PluginHandler
  │   ├── 新风格 → @plugin_handler(ctx)
  │   └── 旧风格 → 7 参数调用
  │
  └─ Stage 5: ResponseSender（兜底）
      ├── 自动回复匹配
      └── @on_fallback 兜底（如 AI 对话）
```

### 多实例路由

一个 GracyBot 进程可同时管理多个 QQ 号。消息到达时：

1. **`/callback`** 接收 NapCat 推送，拿到 `self_id`（消息发给了哪个 QQ）
2. **_get_parser_by_self_id()** 从 AdapterPool 中匹配对应适配器实例
3. **GracyEvent.source** 标记消息来源适配器标签（IdentityTag）
4. **Pipeline** 处理时自动绑定上下文，`gracy_send_msg()` 自动走对账号发送

> 插件无需关心多账号逻辑，Pipeline 自动适配。

## 多实例管理

### 实例配置

每个 QQ 号在 `style/instances/<name>/config.json` 中独立配置：

```json
{
  "platform": "onebot",
  "bot_name": "小号",
  "robot_id": "1323656191",
  "master_id": "192004908",
  "type": "http",
  "http_url": "http://127.0.0.1:2999",
  "callback_port": 3002
}
```

### CLI 管理

```bash
gracy instance list              # 查看所有实例
gracy instance add <name>        # 添加新实例（支持选项 --robot / --master 等）
gracy instance enable <name>     # 启用实例（下次启动生效）
gracy instance disable <name>    # 禁用实例（下次启动跳过）
gracy instance remove <name>     # 删除实例
```

### 插件兼容

旧插件无需修改即可在多账号环境下正常工作：

- `gracy_send_msg()` 自动路由到消息来源账号发送
- `gracy_call_api()` 自动调来源账号的 NapCat API
- `gracy_get_platform_info()` 自动获取来源账号的信息
- 插件内需获取当前 QQ 号时使用 `get_current_robot_id()` 替代 `import ROBOT_ID`
- 插件内需获取主人 QQ 时使用 `get_current_master_id()` 替代 `import MASTER_ID`

## 注意事项

- 本框架由**大学生团队**开发，部分代码由 AI 辅助生成（已标注于源码注释中）
- 框架基于 Python 3.11+，建议使用 3.11+ 以获得最佳异步性能
- Windows 用户请确保系统区域设置为 **UTF-8**（或使用 Python 3.11+ 的 UTF-8 模式）
- Linux 用户推荐使用 systemd 自启（`gracy autostart`）确保持久运行
