## 消息段体系

所有消息段定义在 `core/gracy_adapter/message.py`。

### 消息段类型

| 类 | 字段 | 构造示例 | 说明 |
|---|---|---|---|
| `GracyText` | `text: str` | `GracyText("你好")` | 纯文本 |
| `GracyImage` | `file_path / url / file_data` | `GracyImage(file_path="1.png")` | 图片（三选一） |
| `GracyAt` | `target_id: str` | `GracyAt("123456")` | @某人 |
| `GracyReply` | `message_id: str` | `GracyReply("msg_001")` | 引用回复 |
| `GracyVoice` | `file_path / url` | `GracyVoice(url="...")` | 语音 |
| `GracyFile` | `file_path / url` | `GracyFile(file_path="doc.pdf")` | 文件 |

### 图片三选一

```python
# 本地文件
GracyImage(file_path="path/to/image.png")

# 网络 URL
GracyImage(url="https://example.com/image.png")

# 二进制数据
with open("image.png", "rb") as f:
    GracyImage(file_data=f.read())
```

## 发送消息

### 新风格

```python
from core.gracy_adapter.message import GracyText, GracyImage, GracyAt, GracyReply

await ctx.send(GracyText(text="你好"))
await ctx.send(GracyImage(file_path="1.png"))

# 组合发送（多条消息段）
await ctx.send(
    GracyText(text="这是图片："),
    GracyImage(file_path="1.png"),
)

# 快捷回复
await ctx.reply("你好")  # 等价于 ctx.send(GracyText(text="你好"))

# 指定聊天类型
await ctx.send(GracyText(text="私聊"), ct="private")

# 回复引用 + @
await ctx.send(
    GracyReply(message_id="123"),
    GracyText(text="回复内容"),
    GracyAt(target_id="456"),
)
```

### 旧风格

> ⚠️ `gracy_send_msg` 是 `async` 函数，需在 `async def` 环境中使用 `await` 调用。

```python
from core.gracy_adapter.send import gracy_send_msg
from core.gracy_adapter.message import GracyText, GracyImage

await gracy_send_msg(target_id, GracyText(text="你好"), chat_type="private")
await gracy_send_msg(target_id, GracyImage(file_path="1.png"), chat_type="group")
```

### 多实例适配

多账号场景下，以下函数会自动适配当前消息来源的账号，无需额外传参：

```python
# 自动路由到当前消息来源的适配器
await gracy_send_msg(target_id, GracyText("hi"), chat_type="private")

# 手动指定目标适配器（特殊场景）
await gracy_send_msg(target_id, GracyText("hi"), chat_type="private", tag=my_tag)
```

- `gracy_send_msg()` — 无 tag 时自动使用当前消息上下文中的适配器
- `gracy_call_api()` — 同上
- `gracy_get_platform_info()` — 同上

## 适配器架构

```
            ┌──────────────────────┐
            │     GracyAdapter      │  <-- 抽象基类
            │  +parse_event(data)   │
            │  +send(segments)      │
            └──────────┬───────────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
   GracyOneBot   GracyOneBotWS   (你的新适配器)
   (HTTP回调)     (WebSocket)
```

### 核心接口

```python
class GracyAdapter(ABC):
    @abstractmethod
    def start(self, on_event: Callable[[GracyEvent], None]) -> None:
        """启动适配器，传入事件回调"""

    @abstractmethod
    def send(self, target: str, segments: List[GracyMsg], chat_type: str) -> bool:
        """发送消息段到平台"""

    @abstractmethod
    def stop(self) -> None:
        """停止适配器，释放资源"""

    @abstractmethod
    def get_platform_info(self) -> dict:
        """获取平台统计信息"""
```

## 扩展新平台

继承 `GracyAdapter` 即可支持新 IM 平台：

```python
from core.gracy_adapter import GracyAdapter, GracyEvent
from core.gracy_adapter.message import GracyMsg


class MyPlatformAdapter(GracyAdapter):
    def parse_event(self, data: dict) -> Optional[GracyEvent]:
        """将平台 webhook 数据转为 GracyEvent"""
        return GracyEvent(
            sender_id=str(data["user_id"]),
            target_id=str(data["chat_id"]),
            chat_type="private",
            segments=[],    # 消息段由 send.py 处理
            raw_text=data.get("text", ""),
            message_id=str(data["id"]),
            nickname=data.get("username", ""),
            is_at_bot=False,
            raw_data=data,
        )

    async def send(self, target: str, *segments: GracyMsg, chat_type: str) -> bool:
        """调用平台 API 发送消息（async）"""
        # 实现平台特定的消息发送
        ...
```

## 消息流时序

```
平台 WebHook / WebSocket
        │
        ▼
GracyAdapter.parse_event(data)
        │
        ▼
GracyEvent（平台无关的中间格式）
        │
        ▼
[按 self_id 路由到对应适配器实例]   ← 多账号时自动匹配
        │
        ▼
EventBus.publish(event)
        │
        ▼
Pipeline.process(event)
        │
        ▼
PluginContext（包含发送方法）
        │
        ▼
ctx.send(GracyText, GracyImage, ...)
        │
        ▼
gracy_send_msg(target, *segments, chat_type)
        │ （自动匹配来源适配器）
        ▼
适配器 send() → 平台原生格式 → 平台 API
```
