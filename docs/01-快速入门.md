## 一分钟启动

```bash
# 1. 克隆项目
git clone https://github.com/MiniYv/GracyBot.git
cd gracybot

# 2. 安装依赖（推荐用清华镜像）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 安装框架本身
pip install . -i https://pypi.tuna.tsinghua.edu.cn/simple --force-reinstall --no-deps

# 4. 配置
cp config.template.json config.json
# 编辑 config.json 配置全局设置（日志、连接模式等）
# 然后在 style/instances/ 下创建实例配置（机器人 QQ 号、管理员等）

# 5. 启动
gracy run
```

> 第一次启动会自动创建 `logs/` 目录和默认插件配置。

## 配置文件

`config.json` 位于项目根目录，核心字段：

| 字段 | 类型 | 说明 | 必填 |
|---|---|---|---|
| `bot_version` | string | 框架版本号 | 否 |
| `callback_port` | int | HTTP 回调监听端口 | 是 |
| `connection_mode` | string | 连接模式 `http` / `ws_forward` / `ws_reverse` | 是 |
| `log_level` | string | 日志级别 `INFO`/`DEBUG`/`WARNING` | 否 |
| `debug_mode` | bool | 调试模式开关 | 否 |
| `auto_replies` | dict | 关键词自动回复 | 否 |

每个 QQ 号的独立配置在 `style/instances/<name>/config.json` 中：

```json
{
    "platform": "onebot",
    "bot_name": "我的QQ",
    "enabled": true,
    "type": "http",
    "robot_id": "你的QQ号",
    "master_id": "管理员QQ号",
    "http_url": "http://127.0.0.1:3000",
    "callback_port": 3002
}
```

多实例只需在 `style/instances/` 下创建多个目录，各自独立配置 `robot_id`、`master_id`、`http_url` 即可。

## 启动机器人

```bash
gracy run                # 正常启动（含 Web 管理面板）
gracy run --no-webui     # 不启动 Web 面板
gracy run --debug        # 输出 DEBUG 级别日志
```

各平台建议：

| 平台 | 建议 |
|---|---|
| **Windows** | 直接用 `gracy run`，建议搭配 NapCat 使用 WS 正向连接 |
| **Linux** | `gracy run` 或 `gracy autostart` 注册 systemd 自启服务 |
| **macOS** | 同上，或用 `launchctl` 注册自启 |

## 验证运行

```bash
gracy status
```

输出示例：

```

项目路径: /path/to/gracybot
Bot ID: 123456  |  管理员: 789012
平台: windows  |  虚拟环境: 否
Python: 3.11.9
运行状态: ✅ 运行中
```

向机器人发送 `/关于` 查看框架版本信息，发送 `/帮助` 查看所有可用命令。

## 安装插件

```bash
gracy plugin list                          # 列出已安装插件
gracy plugin install ./path/to/plugin      # 从本地路径安装
gracy plugin install user/repo             # 从 GitHub 安装
gracy plugin install LLM_Chat              # 重新安装已存在插件的依赖
gracy plugin remove <插件名>               # 卸载插件
```
