## 代码对比

### 新风格（推荐）— 来自 Help_plugin

```python
"""帮助插件 — 查询所有插件命令，返回帮助图片"""
import collections
import os
import logging

from core.decorators import on_command, plugin_handler, PluginContext
from core.gracy_adapter.message import GracyImage
from .core.draw import GracyBotHelpDrawer

_logger = logging.getLogger("Gracy.帮助插件")

_drawer = None

def _get_drawer():
    global _drawer
    if _drawer is None:
        _drawer = GracyBotHelpDrawer({})
    return _drawer

@on_command("/help", "/帮助", "/菜单", "/helps")
@plugin_handler
async def handle_help(ctx: PluginContext):
    """生成帮助图片并发送"""
    from core.plugin_manager import PLUGIN_REGISTRY
    plugin_commands = collections.defaultdict(list)
    for plugin in PLUGIN_REGISTRY:
        name = plugin.get("name", "未知插件")
        if name == "帮助插件":
            continue
        desc = plugin.get("description", "")
        cmd_descs = plugin.get("command_descriptions", {})
        for cmd in plugin.get("commands", []):
            cmd_desc = cmd_descs.get(cmd, "") or desc
            plugin_commands[name].append(f"{cmd}#{cmd_desc}" if cmd_desc else cmd)
    if not plugin_commands:
        await ctx.reply("没有找到任何插件或命令")
        return
    try:
        image = _get_drawer().draw_help_image(dict(plugin_commands))
        temp_path = os.path.join(os.path.dirname(__file__), "data", "temp_help.png")
        os.makedirs(os.path.dirname(temp_path), exist_ok=True)
        with open(temp_path, "wb") as f:
            f.write(image)
        await ctx.send(GracyImage(file_path=temp_path))
    except Exception as e:
        _logger.error(f"生成帮助图片失败: {e}")
        await ctx.reply("生成帮助图片失败，请联系管理员")
```

### 旧风格（兼容）— 改造前的 Help_plugin

```python
"""帮助插件 — 查询所有插件命令，返回帮助图片"""
import collections
import os
import sys

from core.utils import logger
from core.config import *
from core.gracy_adapter.message import GracyImage
from .core.draw import GracyBotHelpDrawer

class HelpPlugin:
    def __init__(self):
        self.config = {}
        self.drawer = GracyBotHelpDrawer(self.config)
    def handle_help(self, message, user_info, group_info):
        valid_commands = ["/help", "/帮助", "/菜单", "/helps"]
        if message.strip() not in valid_commands:
            return None
        help_msg = self.get_all_commands()
        if not help_msg:
            return "没有找到任何插件或命令"
        try:
            image = self.drawer.draw_help_image(help_msg)
            temp_path = os.path.join(os.path.dirname(__file__), "data", "temp_help.png")
            with open(temp_path, "wb") as f:
                f.write(image)
            return GracyImage(file_path=temp_path)
        except Exception as e:
            logger.error(f"生成帮助图片失败: {e}")
            return "生成帮助图片失败，请联系管理员"
    def get_all_commands(self):
        plugin_commands = collections.defaultdict(list)
        try:
            from core.plugin_manager import PLUGIN_REGISTRY
            for plugin_meta in PLUGIN_REGISTRY:
                plugin_name = plugin_meta.get("name", "未知插件")
                if plugin_name == "帮助插件":
                    continue
                commands = plugin_meta.get("commands", [])
                description = plugin_meta.get("description", "")
                cmd_descs = plugin_meta.get("command_descriptions", {})
                for cmd in commands:
                    cmd_desc = cmd_descs.get(cmd, "") or description
                    plugin_commands[plugin_name].append(f"{cmd}#{cmd_desc}" if cmd_desc else cmd)
        except Exception as e:
            logger.error(f"获取插件列表失败: {e}")
            return {}
        return dict(plugin_commands)

_help_plugin_instance = None

async def handle_help(plugin_manager, send_msg, data, sender_id, chat_type, permission, logger):
    global _help_plugin_instance
    if _help_plugin_instance is None:
        _help_plugin_instance = HelpPlugin()
    raw_msg = data.get("text", "")
    result = _help_plugin_instance.handle_help(raw_msg, {"id": sender_id}, {"type": chat_type})
    if result:
        if chat_type == "group":
            target_id = data.get("raw_data", {}).get("group_id", sender_id)
        else:
            target_id = data.get("target_id", sender_id)
        if isinstance(result, GracyImage):
            await send_msg(target_id, result, chat_type=chat_type)
        else:
            await send_msg(target_id, GracyText(text=str(result)), chat_type=chat_type)
```

**代码量对比：新风格 58 行 ⇢ 旧风格 141 行（减少 59%）**

## 差异速查表

| 对比维度 | 新风格 | 旧风格 |
|---|---|---|
| **导入来源** | `from core.decorators import ...` | `from core.gracy_adapter.send import gracy_send_msg` |
| **命令声明** | `@on_command("/cmd")` 装饰器 | TOML `commands = ["/cmd"]` |
| **函数签名** | `async def handler(ctx: PluginContext)` | `async def handler(pm, send, data, sid, ct, perm, log)` |
| **参数数量** | 1 个（ctx） | 7 个 |
| **发送消息** | `await ctx.reply("text")` | `await send_msg(tid, GracyText("..."), chat_type=ct)` |
| **获取消息** | `ctx.raw_text` | `data.get("text", "")` |
| **目标 ID** | `ctx.target_id` | `data.get("target_id", sender_id)` |
| **异步支持** | 原生 async/await | 原生 async/await |
| **类型提示** | 完整 dataclass 类型 | 无，手动处理 |
| **权限控制** | `@require_permission("master")` 声明式 | handler 内手动判断 |
| **频率限制** | `@rate_limit(max_calls=5)` 声明式 | 无内置支持 |
| **冷却时间** | `@cooldown(seconds=3)` 声明式 | 无内置支持 |
| **模板代码** | 少 | 多（需手动解析 data） |
| **学习成本** | 需了解装饰器 | 需了解 7 参数含义 |

## 优缺点分析

### 新风格

**优点：**

- 代码量减少约 **50%**（对比旧风格 Help_plugin：58 行 vs 141 行）
- 声明式控制：权限、频率、冷却一键添加
- 完整的 IDE 类型提示（ctx.xxx 自动补全）
- 异步原生，高阶开发更自然
- `ctx.reply()` / `ctx.send()` 简化发送

**缺点：**

- 需要理解装饰器叠加顺序
- `@on_fallback` 兜底暂不支持新风格

### 旧风格

**优点：**

- 简单直接：函数 + 返回值
- 兼容所有历史插件
- 无需理解装饰器体系

**缺点：**

- 7 个参数需要记忆顺序和含义
- 无类型提示，容易传错值
- 权限/频率/冷却需手写逻辑
- 同步函数在异步框架中有性能损耗

## 迁移指南

### 双声明模式

迁移过程中，**TOML 和装饰器可以并存**：

```toml
# metadata.toml
[trigger]
commands = ["/hello", "/hi"]   # TOML 声明
chat_type = ["private", "group"]
```

```python
# plugin.py（两者兼有）
@on_command("/hello")          # 装饰器追加 /hello
@plugin_handler
async def handle(ctx: PluginContext):
    ...
```

框架合并规则：TOML 提供元数据，装饰器追加命令 + 覆盖 handler。**命令列表自动去重**。

### 迁移步骤

```
① 保持 TOML commands 不变（validator 必填校验）
② 在 handler 函数上加 @on_command(*TOML中的命令)
③ 改函数签名为 async def handler(ctx: PluginContext)
④ 替换 data.get("text") → ctx.raw_text
⑤ 替换 send_msg(target, ...) → await ctx.reply() / ctx.send()
⑥ 确认功能正常后，可考虑精简 TOML commands
```
