## 适配器 vs 插件

| | 插件 | 适配器 |
|--|------|--------|
| **位置** | `plugins/` | `core/gracy_adapter/` |
| **职责** | 业务功能（搜索、音乐、管理） | 平台协议对接（收发消息） |
| **导入** | `from graci import ...` | 直接 `from core.xxx import ...` |
| **日志** | `logging.getLogger("Gracy.插件名")` | `logging.getLogger("Adapter.平台名.模块")` |
| **基类** | 无 | 继承 `GracyAdapter` |
| **事件** | 不直接接触 | 必须将平台事件转换为 `GracyEvent` |
| **消息** | 通过 `ctx.send()` 发送 | 直接实现 `send()` 方法 |
| **注册** | 通过 `metadata.toml` + 装饰器 | 通过 `AdapterPool.register()` |
| **修改范围** | 只改插件自身 | 可涉及框架内部（需谨慎） |

## 目录结构

```
core/gracy_adapter/satori/
├── __init__.py          # 导出工厂函数 + 版本
├── adapter.py           # GracyAdapter 实现（主入口）
├── auth.py              # 鉴权逻辑（OAuth2 / Token）
├── gateway.py           # WebSocket 连接管理
├── event.py             # 平台 Event → GracyEvent 映射
├── message.py           # GracyMsg ↔ 平台消息元素互转
├── sender.py            # 发送逻辑（send 方法实现）
├── protocol.py          # 协议常量、类型定义
└── config.py            # 配置读取（可选）
```

### 文件职责

| 文件 | 职责 | 必填 |
|------|------|------|
| `adapter.py` | 实现 `GracyAdapter` 的 `start/stop/send/call_api/get_platform_info` | 是 |
| `event.py` | 将平台原始事件转换为 `GracyEvent` | 是 |
| `message.py` | `GracyMsg` ↔ 平台消息元素双向转换 | 是 |
| `sender.py` | 实际发送逻辑（HTTP API / WebSocket） | 是 |
| `gateway.py` | WebSocket 连接、心跳、重连 | 按需 |
| `auth.py` | Token 获取、刷新 | 按需 |
| `protocol.py` | 协议常量、枚举、类型定义 | 推荐 |
| `config.py` | 读取 `res/config/` 下的配置 | 推荐 |

## 书写顺序（10 层）

> 与插件 10 层对齐，但第 4 层不同——适配器直接访问框架内部。

```python

# 第 1 层：模块文档
# ═══════════════════════════════════════════════════════════
"""Satori 适配器 — 基于 Satori 协议的多平台接入

支持平台：QQ频道、Telegram、Discord 等（通过 satori-python SDK）
"""

import asyncio
import logging
from typing import Callable, Optional

from core.gracy_adapter.adapter import GracyAdapter

    def start(self, on_event: Callable[[GracyEvent], None]) -> None:
        """启动适配器"""

        ...

        ...
```

## GracyAdapter 接口

所有适配器必须实现以下方法：

```python
class GracyAdapter(ABC):

    @abstractmethod
    def start(self, on_event: Callable[[GracyEvent], None]) -> None:
        """启动监听，收到消息时调用 on_event(GracyEvent)"""
        ...

    @abstractmethod
    def send(self, target: str, segments: List[GracyMsg], chat_type: str) -> bool:
        """发送消息，返回是否成功"""
        ...

    @abstractmethod
    def stop(self) -> None:
        """停止并释放资源"""
        ...

    @abstractmethod
    def get_platform_info(self) -> dict:
        """返回 {"platform": str, "friend_count": int|None, ...}"""
        ...

    # 可选
    def call_api(self, action: str, params: dict = None) -> Optional[dict]:
        """通用 API 调用"""
        return None

    def parse_http_request(self, body: dict) -> Optional[GracyEvent]:
        """HTTP 入站解析"""
        return None

    def register_routes(self, app) -> None:
        """注册 HTTP 路由"""
        pass
```

## 事件转换规范

每个适配器必须实现 `平台 Event → GracyEvent` 的转换函数。

### GracyEvent 结构

```python
@dataclass
class GracyEvent:
    sender_id: str                                # 发送者 ID
    target_id: str                                # 目标 ID
    chat_type: str                                # "private" | "group"
    segments: List[GracyMsg]                      # 消息段列表
    raw_text: str = ""                            # 纯文本摘要
    message_id: str = ""                          # 平台消息 ID
    nickname: str = ""                            # 发送者昵称
    is_at_bot: bool = False                       # 是否 @了机器人
    raw_data: dict = field(default_factory=dict)  # 平台原始数据
    source: Optional[IdentityTag] = None          # 来源适配器标签
```

### 转换函数模板

```python
# event.py
def satori_event_to_gracy(
    satori_event,
    tag: IdentityTag,
) -> Optional[GracyEvent]:
    """将 Satori 事件转换为 GracyEvent

    Returns:
        转换成功返回 GracyEvent，不关心的事件返回 None
    """
    # 1. 过滤：只处理消息创建事件
    if satori_event.type != "message_created":
        return None

    # 2. 提取发送者
    sender_id = satori_event.user.id
    nickname = satori_event.user.name or ""

    # 3. 提取目标
    chat_type = "private" if satori_event.channel.type == "private" else "group"
    target_id = satori_event.channel.id

    # 4. 转换消息段
    segments = satori_to_gracy(satori_event.message.content)

    # 5. 提取纯文本
    raw_text = "".join(
        seg.text for seg in segments
        if isinstance(seg, GracyText)
    )

    # 6. 检测 @机器人
    is_at_bot = any(
        seg.target_id == satori_event.self_id
        for seg in segments
        if isinstance(seg, GracyAt)
    )

    return GracyEvent(
        sender_id=sender_id,
        target_id=target_id,
        chat_type=chat_type,
        segments=segments,
        raw_text=raw_text,
        message_id=satori_event.message.id,
        nickname=nickname,
        is_at_bot=is_at_bot,
        raw_data={"satori_event": satori_event},
        source=tag,
    )
```

## 消息转换规范

每个适配器必须实现 `GracyMsg ↔ 平台消息元素` 的双向转换。

### 转换函数模板

```python
# message.py
from core.gracy_adapter.message import (
    GracyText, GracyImage, GracyVoice, GracyAt, GracyReply, GracyFile, GracyVideo, GracyForward, GracyMsg,
)


def gracy_to_satori(segments: List[GracyMsg]) -> List[dict]:
    """GracyMsg 列表 → Satori 消息元素列表"""
    result = []
    for seg in segments:
        if isinstance(seg, GracyText):
            result.append({"type": "text", "data": {"content": seg.text}})
        elif isinstance(seg, GracyImage):
            result.append({"type": "image", "data": {"url": seg.url or seg.file_path}})
        elif isinstance(seg, GracyAt):
            result.append({"type": "at", "data": {"id": seg.target_id}})
        elif isinstance(seg, GracyReply):
            result.append({"type": "reply", "data": {"id": seg.message_id}})
        # ... 其他类型
    return result


def satori_to_gracy(satori_content: str) -> List[GracyMsg]:
    """Satori 消息内容 → GracyMsg 列表"""
    # 解析 Satori 的 JSON 格式消息
    import json
    elements = json.loads(satori_content) if isinstance(satori_content, str) else satori_content

    result = []
    for elem in elements:
        type_ = elem.get("type", "")
        data = elem.get("data", {})

        if type_ == "text":
            result.append(GracyText(text=data.get("content", "")))
        elif type_ == "image":
            result.append(GracyImage(url=data.get("url", "")))
        elif type_ == "at":
            result.append(GracyAt(target_id=data.get("id", "")))
        # ... 其他类型
    return result
```

## 注册到 AdapterPool

适配器工厂函数（在 `__init__.py` 中导出）：

```python
# __init__.py
from core.gracy_adapter.pool import adapter_pool
from core.gracy_adapter.identity import IdentityTag
from .adapter import SatoriAdapter
from .config import load_config


def create_satori_adapter():
    """创建并注册 Satori 适配器"""
    config = load_config()
    if not config.get("satori_url"):
        return None

    adapter = SatoriAdapter(config)
    tag = IdentityTag(
        platform="satori",
        bot_name=config.get("bot_name", "default"),
        conn_type="WebSocket",
    )
    adapter_pool.register(adapter, tag)
    return adapter
```

在 `core/main.py` 中调用：

```python
from core.gracy_adapter.satori import create_satori_adapter
create_satori_adapter()
```
