## 多实例目录（`res/instances/`）

每个实例一个子目录，独立配置，配置字段由各平台适配器自行定义：

```
res/instances/
├── qq_official/
│   └── config.json             # app_id, app_secret, type 等（QQ 官方）
├── onebot_主号/
│   └── config.json             # robot_id, master_id, http_url/ws_host 等（OneBot）
└── onebot_小号/
    └── config.json
```

启动时自动扫描 `res/instances/` 下所有子目录，依次注册到 `AdapterPool`。默认第一项为默认适配器。

## 插件公共 API（`graci.py`）

插件统一通过 `graci.py` 导入框架 API，不直接 `from core.xxx`。`graci.py` 是纯转发层，框架内部重构时只改本文件，插件零改动。

```
插件 → graci.py（~100 行转发）→ core/（内部随便改）
```

```python
# 插件只需这样写：
from graci import GracyText, GracyImage, GracyAt
from graci import gracy_send_msg
from graci import on_command, plugin_handler, PluginContext
from graci import BOT_VERSION, get_current_master_id
```

> 详见 [05-插件开发指南（新风格）](./05-插件开发指南（新风格）.md) 导入顺序部分。

### AdapterPool

| 组件 | 说明 |
|---|---|
| `AdapterPool` | 适配器实例池，注册/注销/查找/发送 |
| `IdentityTag` | 适配器身份标签（platform + bot_name + conn_type），唯一标识 |

消息路由流程：
1. 适配器收到消息 → 发布 `GracyEvent` 到 EventBus
2. EventBus 派发到对应 Runtime 的 Pipeline
3. `GracyEvent.source` 标记来源适配器标签
4. Pipeline 自动绑定上下文 → 回复走对账号

```

├── pool.py                   # AdapterPool 适配器实例池
│
├── onebot/                   # OneBot 11 协议实现
│   ├── http.py               # HTTP 回调适配器
│   ├── ws.py                 # WebSocket 适配器（正反连接）
│   ├── http_routes.py        # /callback 路由注册
│   ├── cq.py                 # CQ 码解析
│   ├── sanitize.py           # 消息清理
│   └── adapter.py            # OneBot 适配器 + create_adapter 工厂
│
└── qq_official/              # QQ 官方机器人实现

    ├── factory.py             # create_adapter 工厂（conn_type_display = WebSocket Gateway）
    ├── api.py                 # HTTP REST API

    ├── sender.py              # 消息发送封装
    └── bind.py                # 主从绑定管理
```

### 设计原则

- **框架核心不感知平台**：core/ 下不得出现任何平台名（onebot/qq_official/telegram...）
- **适配器自描述**：各适配器工厂通过 `conn_type_display` 声明连接方式，框架统一显示
- **配置字段由适配器定义**：`config.json` 的字段格式由各工厂自行解释
- **路由归适配器**：各适配器通过 `register_routes(app)` 注册自己的 HTTP 路由

### 消息段类型（`message.py`）

| 类型 | 字段 | 用途 |
|---|---|---|
| `GracyText(text)` | 字符串 | 文本消息 |
| `GracyImage(file_path/url/file_data)` | 三选一 | 图片消息 |
| `GracyAt(target_id)` | 用户 ID | @某人 |
| `GracyReply(message_id)` | 消息 ID | 回复引用 |
| `GracyVoice(file_path/url)` | 同上 | 语音 |
| `GracyFile(file_path/url)` | 同上 | 文件 |

### 发送函数（`send.py`）

> `gracy_send_msg` 是 `async` 函数，需在异步环境中 `await` 调用。

```python
await gracy_send_msg(target, *segments, chat_type="private")
# target: 目标 ID
# *segments: GracyText / GracyImage / GracyAt ... 任意数量
# chat_type: "private" | "group"
```

## 管道调度（`pipeline/`）

```
pipeline/
├── __init__.py               # Pipeline 类 + 默认 Stage 注册
├── security_filter.py        # Stage 1: SecurityFilter
├── builtin_commands.py       # Stage 2: BuiltinCommands
├── command_matcher.py        # Stage 3: CommandMatcher
├── plugin_handler.py         # Stage 4: PluginHandler
├── response_sender.py        # Stage 5: ResponseSender
└── helpers.py                # 辅助函数
```

每个 Stage 实现在独立文件中，见上方目录树。

| Stage | 类名 | 职责 | 短路条件 |
|---|---|---|---|
| 1 | `SecurityFilter` | 黑名单/审计/监控/日志 | 黑名单命中 |
| 2 | `BuiltinCommands` | `/关机` `/重启` `/开机` `/关于` | 内置命令 |
| 3 | `CommandMatcher` | TOML + 装饰器命令匹配 | 无匹配→继续 |
| 4 | `PluginHandler` | 执行插件 handler，新/旧风格自动识别 | 执行完成 |
| 5 | `ResponseSender` | 自动回复 + @on_fallback 兜底 | 兜底完成 |

## 装饰器体系（`decorators/`）

```

├── __init__.py               # 统一导出

```

### 装饰器叠加顺序

```python
@on_command("/cmd")           # ① 命令注册（最外层）
@require_permission("all")    # ② 权限声明
@rate_limit(max_calls=5)      # ③ 频率限制
@cooldown(seconds=3)          # ④ 冷却时间
@plugin_handler               # ⑤ 核心包装器（最里层）
async def handler(ctx: PluginContext):
    ...
```

## 架构变更记录

### 2026-06-25 — 代码层次清理

**目标**：移除 `core/` 框架层所有平台硬编码，使框架核心平台无关。

| 改动 | 说明 |
|------|------|
| 删除 `core/handler.py` | 原 500+ 行消息分发中心，功能融入 adapter + pipeline |
| 删除 `core/adapter.py` | 原 OneBot 包装类，已有 `gracy_adapter/onebot/adapter.py` 替代 |
| `core/main.py` 清理 | 移除 OneBot 导入、`/callback` 路由、`_parse_cli_args`、`CALLBACK_PORT`/`CONNECTION_MODE` 常量 |
| `core/pipeline/stages.py` 清理 | 移除 `if platform == "onebot"/"qq_official"` 协议映射，无差别显示 |
| `core/config.py` 清理 | 移除 `connection_mode`、`callback_port`、`master_id` 默认值 |
| `IdentityTag` 新增 `conn_type` | 显示连接方式，由各适配器工厂设置（HTTP / WS / WebSocket Gateway） |
| `gracy_session` 重命名 | `user_id` → `sender_id`，`group_id` → `target_id` |
| CLI 实例命令平台化 | 移除 `platform="onebot"`、`callback_port=3002` 默认值 |
| 配置更新 | `res/instances/qq_official/config.json` 添加 `"type": "ws"` |

**新原则**：
- 框架核心不得出现平台名 → `core/` 只负责调度
- 适配器自描述 → 连接方式、配置字段、HTTP 路由均由各适配器自行定义
- `main.py` 不感知平台细节 → 仅做统一注册和生命周期管理
