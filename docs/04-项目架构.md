```
## 多实例目录（`style/instances/`）

每个 QQ 号一个子目录，独立配置：

```
style/instances/
├── 主号/
│   └── config.json             # robot_id, master_id, http_url, callback_port 等
└── 小号/
    └── config.json
```

启动时自动扫描 `style/instances/` 下所有子目录，依次注册到 `AdapterPool`。默认第一项为默认适配器（向后兼容单账号场景）。

### AdapterPool

| 组件 | 说明 |
|---|---|
| `AdapterPool` | 适配器实例池，注册/注销/查找/发送 |
| `IdentityTag` | 适配器身份标签（platform + bot_name），唯一标识 |
| `_http_parsers` | HTTP 事件解析器缓存，按 `robot_id` 索引 |

消息路由流程：
1. NapCat 回调 → 提取 `self_id`
2. `_get_parser_by_self_id()` 匹配对应适配器
3. `GracyEvent.source` 标记来源适配器标签
4. Pipeline 自动绑定上下文 → 回复走对账号
```

## 核心框架（`core/`）

```
core/
├── __init__.py               # 统一导出：core 单例 + 延迟加载
├── main.py                   # 入口：HTTP 服务 + WS 连接 + 插件初始化
├── handler.py                # HTTP 回调处理（旧路径）
├── plugin_manager.py         # 插件管理器：扫描/加载/注册/匹配
│
├── config.py                 # 配置项定义（ConfigItem 注册）
├── config_manager.py         # 配置管理器：读取/缓存/监控变更
├── security.py               # 安全工具：日志脱敏
├── security_manager.py       # 安全管理器：权限/黑名单/频率限制/审计
├── monitor.py                # 监控管理器：性能指标/插件统计/健康检查
├── logger_manager.py         # 日志管理器：结构化日志/上下文日志
├── utils.py                  # 通用工具函数
│
├── gracy_adapter/            # 适配器层
├── pipeline/                 # 管道调度
├── decorators/               # 装饰器体系
├── gracy_session/            # 会话管理
└── tools/                    # 工具模块
    ├── validator.py          # metadata.toml 解析与校验
    └── cli/                  # CLI 命令行工具
```

### `plugin_manager.py` 核心函数

| 函数 | 说明 |
|---|---|
| `PluginManager.init()` | 扫描 `plugins/`，加载所有插件 |
| `get_matched_plugin(raw_msg, ...)` | 按消息匹配命令，返回插件 |
| `get_all_plugins_metadata()` | 获取所有插件信息 |
| `reload_plugin(plugin_name)` | 热重载指定插件 |

### `security_manager.py` 核心函数

| 函数 | 说明 |
|---|---|
| `check_permission(user_id, level)` | 权限校验 |
| `log_audit_event(user_id, action, ...)` | 审计日志 |
| `check_rate_limit(key)` | 频率限制 |
| `validate_input(data)` | 输入验证 |

## 适配器层（`gracy_adapter/`）

```
gracy_adapter/
├── __init__.py               # 统一导出消息段 / 事件 / 适配器
├── adapter.py                # GracyAdapter 抽象基类
├── event.py                  # GracyEvent 事件定义
├── message.py                # 消息段类型（GracyText/GracyImage/GracyAt...）
├── send.py                   # gracy_send_msg 统一发送入口
├── gracy_bot.py              # GracyBot 统一入口
│
└── onebot/                   # OneBot 11 协议实现
    ├── http.py               # HTTP 回调适配器
    ├── ws.py                 # WebSocket 适配器（正反连接）
    ├── cq.py                 # CQ 码解析
    ├── sanitize.py           # 消息清理
    └── adapter.py            # OneBot 协议常量
```

### 消息段类型（`message.py`）

| 类型 | 字段 | 用途 |
|---|---|---|
| `GracyText(text)` | 字符串 | 文本消息 |
| `GracyImage(file_path/url/file_data)` | 三选一 | 图片消息 |
| `GracyAt(target_id)` | 用户 ID | @某人 |
| `GracyReply(message_id)` | 消息 ID | 回复引用 |
| `GracyVoice(file_path/url)` | 同上 | 语音 |
| `GracyFile(file_path/url)` | 同上 | 文件 |

### 发送函数（`send.py`）

> `gracy_send_msg` 是 `async` 函数，需在异步环境中 `await` 调用。

```python
await gracy_send_msg(target, *segments, chat_type="private")
# target: 目标 ID
# *segments: GracyText / GracyImage / GracyAt ... 任意数量
# chat_type: "private" | "group"
```

## 管道调度（`pipeline/`）

```
pipeline/
├── __init__.py               # Pipeline 类 + 默认 Stage 注册
└── stages.py                 # 5 个 Stage 实现
```

| Stage | 类名 | 职责 | 短路条件 |
|---|---|---|---|
| 1 | `SecurityFilter` | 黑名单/审计/监控/日志 | 黑名单命中 |
| 2 | `BuiltinCommands` | `/关机` `/重启` `/开机` `/关于` | 内置命令 |
| 3 | `CommandMatcher` | TOML + 装饰器命令匹配 | 无匹配→继续 |
| 4 | `PluginHandler` | 执行插件 handler，新/旧风格自动识别 | 执行完成 |
| 5 | `ResponseSender` | 自动回复 + @on_fallback 兜底 | 兜底完成 |

## 装饰器体系（`decorators/`）

```
decorators/
├── __init__.py               # 统一导出
├── registration.py           # @on_command / @on_regex / @on_keyword / @on_fallback
├── handler.py                # @plugin_handler（核心包装器）
├── context.py                # PluginContext 数据类
├── security.py               # @require_permission / @rate_limit / @cooldown
├── session.py                # @with_session
└── async_utils.py            # @async_retry / @background
```

### 装饰器叠加顺序

```python
@on_command("/cmd")           # ① 命令注册（最外层）
@require_permission("all")    # ② 权限声明
@rate_limit(max_calls=5)      # ③ 频率限制
@cooldown(seconds=3)          # ④ 冷却时间
@plugin_handler               # ⑤ 核心包装器（最里层）
async def handler(ctx: PluginContext):
    ...
```

## 插件标准目录结构

```
plugins/YourPlugin/
├── metadata.toml              # 元数据（必填，8 个必填字段）
├── YourPlugin.py              # 主逻辑（handler + 装饰器）
├── requirements.txt           # Python 依赖（可选）
├── core/                      # 子模块（可选）
│   ├── draw.py
│   └── ...
└── __init__.py                # 可为空
```
