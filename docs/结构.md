# 消息处理全链路

```
OneBot HTTP/WS  ─┐
                  ├─→ EventBus.publish(event)
QQ Official WS  ─┘       │
                         ▼
                Runtime.pipeline.process(event)
                         │
                         ▼
                SecurityFilter._log_via_styling()
                         │
                         ▼
                logger_manager.log_with_context()
                         │
                         ▼
                StructuredLogFormatter._format_console()
                         │
                         ▼
                format_context_to_chinese() + format_message_to_chinese()
                         │
                         ▼
                写入 gracybot.log + 控制台输出
```
