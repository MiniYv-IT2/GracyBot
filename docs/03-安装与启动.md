## 安装步骤

### 方式一：直接安装（推荐）

```bash
# 1. 克隆
git clone https://github.com/MiniYv/GracyBot.git
cd gracybot

# 2. 创建虚拟环境（可选但推荐）
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 安装框架 CLI
pip install . -i https://pypi.tuna.tsinghua.edu.cn/simple --force-reinstall --no-deps

# 5. 配置
cp config.template.json config.json
# 编辑 config.json
```

### 方式二：开发模式安装

```bash
pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple --no-deps
```

代码修改后无需重新安装，直接 `gracy run` 即可生效。

## 配置 NapCat（QQ 协议端）

> 通过 WebSocket 正向连接 NapCat，推荐方案。

1. 下载 NapCat：https://github.com/NapNeko/NapCat
2. 启动 NapCat 后，在 NapCat 配置中添加 WebSocket 客户端：

```json
{
    "wsServer": {
        "enable": true,
        "servers": [
            {
                "host": "127.0.0.1",
                "port": 3001
            }
        ]
    }
}
```

3. 在 `style/instances/` 下创建实例配置文件，`type` 设为 `ws_forward`，填写 `host`、`port`、`robot_id`、`master_id` 等。

## 启动方式

```bash
# 基础启动
gracy run

# 带参数启动
gracy run --debug          # DEBUG 日志级别
gracy run --no-webui       # 不启动 Web 管理面板

# 查看状态
gracy status

# 停止
gracy stop

# 查看帮助
gracy --help
gracy plugin --help
```

## 平台专项说明

### Windows

| 注意事项 | 说明 |
|---|---|
| **编码问题** | 建议设置系统区域为 UTF-8（设置 → 时间和语言 → 语言和区域 → 管理语言设置 → 更改系统区域设置 → 勾选 Beta 版 UTF-8） |
| **NapCat 搭配** | 推荐 WebSocket 正向模式，NapCat 做服务端，GracyBot 做客户端 |
| **后台运行** | 使用 `gracy run` 直接在前台运行；需后台可用 `pythonw` 包装 |
| **截图功能** | Screenshot 插件需管理员权限运行 |

### Linux

| 注意事项 | 说明 |
|---|---|
| **推荐系统** | Debian 11+ / Ubuntu 22.04+ / CentOS 8+ |
| **自启服务** | `gracy autostart` 注册 systemd 用户服务 |
| **持久运行** | systemd 自动保活，崩溃后自动重启 |
| **资源占用** | 空闲时约 80 MB 内存 |

```bash
# 注册开机自启
gracy autostart

# 查看服务状态
systemctl --user status gracybot

# 查看实时日志
journalctl --user -u gracybot -f
```

### macOS

| 注意事项 | 说明 |
|---|---|
| **编码** | macOS 默认 UTF-8，无需额外配置 |
| **自启** | 框架自动检测 macOS 并使用 `launchctl` 注册 |
| **权限** | 截图功能需授予屏幕录制权限 |

### Termux（Android）

| 注意事项 | 说明 |
|---|---|
| **安装 Python** | `pkg install python` |
| **依赖** | `pkg install libxml2 libxslt` |
| **运行** | 前台运行，建议用 `tmux` 保持会话 |
| **限制** | 后台运行受限，息屏可能断连 |

## 调试模式

```bash
# 开启 DEBUG 日志
gracy run --debug

# 日志文件位置
logs/gracybot.log           # 主日志
logs/gracybot_error.log     # 错误日志

# 实时跟踪日志（Windows PowerShell）
Get-Content logs/gracybot.log -Tail 20 -Wait

# 实时跟踪日志（Linux/macOS）
tail -f logs/gracybot.log
```

### 调试技巧

| 场景 | 做法 |
|---|---|
| 插件没加载 | 看启动日志 `📊 共注册成功 N 个插件` |
| 命令没匹配 | 开启 DEBUG 看 `[CommandMatcher]` 日志 |
| AI 回复失败 | 检查 `plugins/LLM_Chat/config.json` 中的 API Key |
| WebSocket 断连 | 看 `[OneBotWS]` 日志中的错误信息 |
| 插件报错 | 看 `[PluginHandler] 异常` 日志，含完整 Traceback |
