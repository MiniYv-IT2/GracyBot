## 适用场景

| 场景 | 推荐风格 |
|---|---|
| 新插件开发 | **新风格**（装饰器） |
| 维护旧插件 | 旧风格 |
| 简单响应插件 | 新风格 |
| 复杂业务（需同步库） | 新风格（`@plugin_handler` 自动兼容同步） |
| 迁移过渡期 | 两种风格并存（TOML + 装饰器互补） |

## 完整示例

### metadata.toml

```toml
[plugin]
name        = "示例插件"
version     = "1.0.0"
author      = "开发者名"
description = "插件功能描述"

[handler]
entry       = "handle_example"

[trigger]
commands       = ["/example", "/demo"]
chat_type      = ["private", "group"]
permission     = "all"
is_at_required = false

[trigger.command_descriptions]
"/example" = "示例命令说明"
```

### 主文件

```python
"""示例插件 — 说明"""
import logging

from core.gracy_adapter.send import gracy_send_msg
from core.gracy_adapter.message import GracyText, GracyImage

_logger = logging.getLogger("Gracy.示例插件")


async def handle_example(plugin_manager, send_msg, data, sender_id, chat_type, permission, log_func):
    """示例处理函数（7 参数，async）"""
    raw_msg = data.get("text", "")
    target_id = data.get("target_id", sender_id)

    if "/status" in raw_msg:
        await send_msg(target_id, GracyText(text="系统正常"), chat_type=chat_type)

    # 发送图片
    await send_msg(target_id, GracyImage(file_path="path.png"), chat_type=chat_type)
```

## 7 参数详解

| 参数 | 类型 | 说明 | 常用操作 |
|---|---|---|---|
| `plugin_manager` | PluginManager | 插件管理器实例 | `pm.get_all_plugins_metadata()` |
| `send_msg` | function | 发送消息函数 | `send_msg(target, GracyText(...), chat_type=ct)` |
| `data` | dict | 消息数据 | `data.get("text")` / `data.get("raw_data")` / `data.get("target_id")` |
| `sender_id` | str | 发送者 QQ | 权限判断 |
| `chat_type` | str | `"private"` / `"group"` | 逻辑分支 |
| `permission` | str | `"all"` / `"master"` | 权限级别 |
| `log_func` | Logger | 日志器 | `log_func.info("消息")` |

### data 字典字段

```python
data = {
    "text": "用户消息文本",          # 净化文本
    "nickname": "昵称",
    "images": ["file_id1"],         # 图片文件 ID
    "ats": ["@的用户ID"],
    "target_id": "目标ID",           # 私聊=发送者，群聊=群号
    "chat_type": "private/group",
    "raw_data": {...}               # OneBot 原始数据（透传）
}
```

## 调用时序

```
PluginHandler（Pipeline Stage 4）
  │
  ├─ 签名检测 (inspect.signature)
  │   ├─ 1 参数 (ctx)  → 新风格 @plugin_handler
  │   └─ 7 参数         → 旧风格函数
  │
  └─ 旧风格调用
      │
      ├─ plugin_manager  →  插件管理器
      ├─ gracy_send_msg  →  发送函数
      ├─ data            →  消息数据（_build_plugin_data）
      ├─ sender_id       →  发送者
      ├─ chat_type       →  聊天类型
      ├─ "all"           →  权限（固定传）
      └─ _logger         →  日志器
```

## 模板示例（SysInfo_plugin）

```python
"""系统状态插件 — 展示系统资源占用"""
import platform
import logging

from core.gracy_adapter.send import gracy_send_msg
from core.gracy_adapter.message import GracyImage, GracyText

_logger = logging.getLogger("Gracy.SysInfo")


async def handle_sysinfo(plugin_manager, send_msg, data, sender_id, chat_type, permission, log_func):
    """查询系统运行状态"""
    raw_msg = data.get("text", "")
    target_id = data.get("target_id", sender_id)

    if "/status" in raw_msg:
        reply = f"系统: {platform.system()}\nPython: {platform.python_version()}"
        await send_msg(target_id, GracyText(text=reply), chat_type=chat_type)
```

## 注意点

| 问题 | 处理方式 |
|---|---|
| **同步/异步** | 旧风格 handler 现在统一为 `async def`（框架 100% 异步），内部调用 `send_msg` 需加 `await` |
| **参数名** | 旧风格使用 `send_msg` 参数发送，不要重新 `from core.gracy_adapter.send import gracy_send_msg` |
| **target_id** | 从 `data.get("target_id", sender_id)` 获取，不要手动拼接 |
| **TOML 命令** | `commands` 是框架匹配的唯一依据，handler 内无需再次校验命令 |
| **返回 None** | 旧 handler 不返回值，框架自动处理 |
