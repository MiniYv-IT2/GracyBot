## 开发前准备

```bash
gracy plugin list           # 查看已有插件
gracy plugin install ./my-plugin  # 安装本地插件
```

所有插件放在 `plugins/` 目录下，每个插件一个子目录：

```
plugins/YourPlugin/
├── metadata.toml            # 必填：元数据
├── YourPlugin.py            # 必填：主逻辑文件
├── requirements.txt         # 可选：Python 依赖
├── core/                    # 可选：子模块
│   └── draw.py
└── __init__.py              # 可选：可为空
```

## 导入顺序

> 框架已自动处理 `sys.path`，插件无需手动追加路径。

```python
# 第 1 层：标准库
import os
import logging

# 第 2 层：框架装饰器
from core.decorators import on_command, plugin_handler, PluginContext

# 第 3 层：框架消息段（如需发送图片等）
from core.gracy_adapter.message import GracyText, GracyImage

# 第 4 层：框架工具
from core.config import get_current_master_id, get_current_robot_id  # 多账号适配
from core.plugin_manager import PLUGIN_REGISTRY  # 插件注册池

# 第 5 层：插件自身模块
from .core.draw import MyDrawer

_logger = logging.getLogger("Gracy.插件名")
```

> 注意：`from core.utils import logger` 是框架内部日志器，插件应使用 `logging.getLogger("Gracy.插件名")` 获取独立的日志实例。

## 完整示例（Help_plugin）

> Help_plugin 是第一个按新风格编写的插件，以此为模板。

### metadata.toml

```toml
[plugin]
name        = "我的插件"
version     = "1.0.0"
author      = "开发者名"
description = "一句话描述功能"

[handler]
entry       = "handle_my_plugin"

[trigger]
commands       = ["/cmd1", "/cmd2"]
chat_type      = ["private", "group"]
permission     = "all"
is_at_required = false
```

### 主文件

```python
"""我的插件 — 一句话描述"""
import logging

from core.decorators import on_command, plugin_handler, PluginContext
from core.gracy_adapter.message import GracyText, GracyImage

_logger = logging.getLogger("Gracy.我的插件")


@on_command("/hello", "/hi")
@plugin_handler
async def handle_my_plugin(ctx: PluginContext):
    """处理函数：一行文档即 CLI 帮助"""
    # 获取消息
    user_input = ctx.raw_text

    # 发送回复
    await ctx.reply(f"你说了：{user_input}")
    # 或
    await ctx.send(GracyText(text="你也可以这样发送"))
```

## PluginContext 详解

> `PluginContext` 是框架注入给 handler 的统一上下文对象，包含消息来源、内容和工具函数。

| 属性 | 类型 | 说明 |
|---|---|---|
| `sender_id` | str | 发送者 ID（QQ 号） |
| `target_id` | str | 目标 ID（私聊=发送者，群聊=群号） |
| `chat_type` | str | `"private"` 或 `"group"` |
| `nickname` | str | 发送者昵称 |
| `raw_text` | str | 原始消息全文 |
| `text` | str | 净化后的文本（去掉 @ 等） |
| `images` | list[str] | 图片文件 ID 列表 |
| `ats` | list[str] | @的用户 ID 列表 |
| `is_at_bot` | bool | 是否 @了机器人 |
| `command` | str | 匹配到的触发指令 |
| `plugin_name` | str | 当前插件名称 |
| `adapter_tag` | IdentityTag | 消息来源适配器标签（多账号时区分是哪个实例收到消息） |

| 方法 | 说明 |
|---|---|
| `ctx.reply(text)` | 快捷回复文本（自动路由到消息来源账号） |
| `ctx.send(*segments, ct=None)` | 发送任意消息段（自动路由到消息来源账号） |

## 装饰器速查表

| 装饰器 | 参数 | 说明 | 必填 |
|---|---|---|---|
| `@on_command("/a", "/b")` | 命令列表 | 注册触发命令 | 是 |
| `@plugin_handler` | 无 | 核心包装器，注入 ctx | 是 |
| `@require_permission("master")` | `"all"` / `"master"` | 权限校验 | 否 |
| `@require_master` | 无 | 快捷主人权限 | 否 |
| `@rate_limit(max_calls=5, period=60)` | 次数 / 周期(秒) | 频率限制 | 否 |
| `@cooldown(seconds=3)` | 冷却秒数 | 命令冷却 | 否 |

## 消息发送方式

```python
# 方式 1：快捷回复（仅文本）
await ctx.reply("你好")

# 方式 2：发送消息段
await ctx.send(GracyText(text="文本消息"))
await ctx.send(GracyImage(file_path="path/to/image.png"))
await ctx.send(GracyImage(url="https://example.com/image.png"))

# 方式 3：组合发送
await ctx.send(
    GracyText(text="这是图片："),
    GracyImage(file_path="path/to/image.png"),
)

# 方式 4：强制指定聊天类型
await ctx.send(GracyText(text="私聊发送"), ct="private")
```

## 装饰器示例：权限与限流

```python
from core.decorators import (
    on_command, plugin_handler, PluginContext,
    require_permission, require_master,
    rate_limit, cooldown,
)


# 仅主人可用
@on_command("/admin")
@require_master
@plugin_handler
async def handle_admin(ctx: PluginContext):
    await ctx.reply("这是管理员命令")


# 频率限制：60 秒内最多 5 次
@on_command("/search")
@rate_limit(max_calls=5, period=60)
@plugin_handler
async def handle_search(ctx: PluginContext):
    await ctx.reply("搜索中...")


# 冷却：3 秒内不可重复触发
@on_command("/status")
@cooldown(seconds=3)
@plugin_handler
async def handle_status(ctx: PluginContext):
    await ctx.reply("系统正常")
```

## @on_fallback 兜底处理

> 当没有命令匹配时，标记了 `@on_fallback` 的 handler 会被 `ResponseSender` 调用。

适合用于 AI 对话等"接住所有未匹配消息"的场景。

```python
from core.decorators import on_fallback, plugin_handler, PluginContext


@on_fallback()
@plugin_handler
async def handle_fallback(ctx: PluginContext):
    """处理所有未匹配的消息"""
    await ctx.reply(f"我不理解：{ctx.raw_text}")
```

> `@on_fallback` 支持新风格（`ctx: PluginContext`）和旧风格两种签名。

## 常见参数场景

| 场景 | 代码 |
|---|---|
| 判断私聊/群聊 | `if ctx.chat_type == "private":` |
| 判断是否被 @ | `if ctx.is_at_bot:` |
| 获取发送者昵称 | `nick = ctx.nickname` |
| 匹配命令参数 | `args = ctx.raw_text[len(ctx.command):].strip()` |
| 检查主人 | `get_current_master_id() == ctx.sender_id` |
| 获取当前账号 | `get_current_robot_id()` |
| 发送图片 | `await ctx.send(GracyImage(file_path="1.png"))` |
| 群聊中@某人 | `await ctx.send(GracyText(text="hi"), GracyAt(target_id="123"))` |
| 引用回复 | `await ctx.send(GracyReply(message_id="123"), GracyText(text="回复"))` |
