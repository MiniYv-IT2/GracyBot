## 开发前准备

```bash
gracy plugin list           # 查看已有插件
gracy plugin install ./my-plugin  # 安装本地插件
```

所有插件放在 `plugins/` 目录下，每个插件一个子目录：

```
plugins/YourPlugin/
├── metadata.toml            # 必填：元数据
├── YourPlugin.py            # 必填：主逻辑文件
├── requirements.txt         # 可选：Python 依赖
├── core/                    # 可选：子模块
│   └── draw.py
└── __init__.py              # 可选：可为空
```

## 导入顺序

> 框架已自动处理 `sys.path`，插件无需手动追加路径。
> 所有框架 API 统一通过 `graci` 模块导入（外观层），不直接 `from core.xxx`。

```python
# 第 1 层：标准库
import os

# 第 2 层：框架装饰器
from graci import on_command, plugin_handler, PluginContext, get_logger

# 第 3 层：框架消息段（如需发送图片等）
from graci import GracyText, GracyImage

# 第 4 层：框架工具
from graci import get_current_master_id, get_current_robot_id  # 多账号适配
from graci import plugin_manager  # 插件管理器

# 第 5 层：插件自身模块
from .core.draw import MyDrawer

logger = get_logger("插件名")
```

> 注意：插件应使用 `from graci import get_logger; logger = get_logger("插件名")` 获取日志实例，不要用 `from graci import logger` 或 `logging.getLogger`。

## 完整示例（Help_plugin）

> Help_plugin 是第一个按新风格编写的插件，以此为模板。

### metadata.toml

```toml
[plugin]
name        = "我的插件"
version     = "1.0.0"
author      = "开发者名"
description = "一句话描述功能"

[handler]
entry       = "handle_my_plugin"

[trigger]
commands       = ["/cmd1", "/cmd2"]
chat_type      = ["private", "group"]
permission     = "all"
is_at_required = false
```

### 主文件

```python
"""我的插件 — 一句话描述"""

from graci import on_command, plugin_handler, PluginContext, get_logger
from graci import GracyText, GracyImage

logger = get_logger("我的插件")


@on_command("/hello", "/hi")
@plugin_handler
async def handle_my_plugin(ctx: PluginContext):
    """处理函数：一行文档即 CLI 帮助"""
    # 获取消息
    user_input = ctx.raw_text

    # 发送回复
    await ctx.reply(f"你说了：{user_input}")
    # 或
    await ctx.send(GracyText(text="你也可以这样发送"))
```

## PluginContext 详解

> `PluginContext` 是框架注入给 handler 的统一上下文对象，包含消息来源、内容和工具函数。

| 属性 | 类型 | 说明 |
|---|---|---|
| `sender_id` | str | 发送者 ID（QQ 号） |
| `target_id` | str | 目标 ID（私聊=发送者，群聊=群号） |
| `chat_type` | str | `"private"` 或 `"group"` |
| `nickname` | str | 发送者昵称 |
| `raw_text` | str | 原始消息全文 |
| `text` | str | 净化后的文本（去掉 @ 等） |
| `images` | list[str] | 图片文件 ID 列表 |
| `ats` | list[str] | @的用户 ID 列表 |
| `is_at_bot` | bool | 是否 @了机器人 |
| `command` | str | 匹配到的触发指令 |
| `plugin_name` | str | 当前插件名称 |
| `adapter_tag` | IdentityTag | 消息来源适配器标签（多账号时区分是哪个实例收到消息） |

| 方法 | 说明 |
|---|---|
| `ctx.reply(text)` | 快捷回复文本（自动路由到消息来源账号） |
| `ctx.send(*segments, ct=None)` | 发送任意消息段（自动路由到消息来源账号） |

## 装饰器速查表

| 装饰器 | 参数 | 说明 | 必填 |
|---|---|---|---|
| `@on_command("/a", "/b")` | 命令列表 | 注册触发命令 | 是 |
| `@plugin_handler` | 无 | 核心包装器，注入 ctx | 是 |
| `@require_permission("master")` | `"all"` / `"master"` | 权限校验 | 否 |
| `@require_master` | 无 | 快捷主人权限 | 否 |
| `@rate_limit(max_calls=5, period=60)` | 次数 / 周期(秒) | 频率限制 | 否 |
| `@cooldown(seconds=3)` | 冷却秒数 | 命令冷却 | 否 |

## 消息发送方式

```python
# 方式 1：快捷回复（仅文本）
await ctx.reply("你好")

# 方式 2：发送消息段
await ctx.send(GracyText(text="文本消息"))
await ctx.send(GracyImage(file_path="path/to/image.png"))
await ctx.send(GracyImage(url="https://example.com/image.png"))

# 方式 3：组合发送
await ctx.send(
    GracyText(text="这是图片："),
    GracyImage(file_path="path/to/image.png"),
)

# 方式 4：强制指定聊天类型
await ctx.send(GracyText(text="私聊发送"), ct="private")
```

## 装饰器示例：权限与限流

```python
from graci import (
    on_command, plugin_handler, PluginContext,
    require_permission, require_master,
    rate_limit, cooldown,
)


# 仅主人可用
@on_command("/admin")
@require_master
@plugin_handler
async def handle_admin(ctx: PluginContext):
    await ctx.reply("这是管理员命令")


# 频率限制：60 秒内最多 5 次
@on_command("/search")
@rate_limit(max_calls=5, period=60)
@plugin_handler
async def handle_search(ctx: PluginContext):
    await ctx.reply("搜索中...")


# 冷却：3 秒内不可重复触发
@on_command("/status")
@cooldown(seconds=3)
@plugin_handler
async def handle_status(ctx: PluginContext):
    await ctx.reply("系统正常")
```

## @on_fallback 兜底处理

> 当没有命令匹配时，标记了 `@on_fallback` 的 handler 会被 `ResponseSender` 调用。

适合用于 AI 对话等"接住所有未匹配消息"的场景。

```python
from graci import on_fallback, plugin_handler, PluginContext


@on_fallback()
@plugin_handler
async def handle_fallback(ctx: PluginContext):
    """处理所有未匹配的消息"""
    await ctx.reply(f"我不理解：{ctx.raw_text}")
```

> `@on_fallback` 支持新风格（`ctx: PluginContext`）和旧风格两种签名。

## 常见参数场景

| 场景 | 代码 |
|---|---|
| 判断私聊/群聊 | `if ctx.chat_type == "private":` |
| 判断是否被 @ | `if ctx.is_at_bot:` |
| 获取发送者昵称 | `nick = ctx.nickname` |
| 匹配命令参数 | `args = ctx.raw_text[len(ctx.command):].strip()` |
| 检查主人 | `get_current_master_id() == ctx.sender_id` |
| 获取当前账号 | `get_current_robot_id()` |
| 发送图片 | `await ctx.send(GracyImage(file_path="1.png"))` |
| 群聊中@某人 | `await ctx.send(GracyText(text="hi"), GracyAt(target_id="123"))` |
| 引用回复 | `await ctx.send(GracyReply(message_id="123"), GracyText(text="回复"))` |

## 标准插件模板（完整规范）

> 以下是 GracyBot 插件的标准结构。所有新插件必须遵循此模板书写。
> 旧式插件迁移到新风格时，也应按此模板重构。

### 目录结构

```
plugins/MyPlugin/
├── metadata.toml            # 必填：插件元数据（给插件商店 + 框架加载用）
├── MyPlugin.py              # 必填：主逻辑文件（文件名必须 = 目录名）
├── __init__.py              # 可选：可为空，包标识用
├── config.py                # 可选：配置模型（如需读取 res/config/ 下的 JSON）
├── requirements.txt         # 可选：第三方依赖
├── core/                    # 可选：子模块目录
│   ├── __init__.py
│   ├── api.py               # API 调用
│   ├── draw.py              # 绘图逻辑
│   └── parser.py            # 数据解析
├── data/                    # 可选：运行时数据（缓存、临时文件）
│   └── cache/
└── README.md                # 可选：插件说明
```

### metadata.toml 完整模板

```toml
[plugin]
name        = "我的插件"              # 必填：显示名（中文，插件商店展示）
version     = "1.0.0"                # 必填：语义化版本
author      = "开发者名"              # 必填：作者
description = "一句话描述功能"         # 必填：功能简介（插件商店卡片）
priority    = 50                     # 可选：优先级，越大越先匹配，默认 50
icon        = ""                     # 可选：图标路径或 URL（插件商店展示）
dependencies = []                    # 可选：依赖插件

[handler]
entry       = "handle_my_plugin"     # 必填：主文件中的入口函数名

[trigger]
commands       = ["/cmd1", "/cmd2"]  # 必填：触发命令（非空列表）
chat_type      = ["private", "group"]# 必填：适用场景
permission     = "all"               # 必填："all" 或 "master"
is_at_required = false               # 必填：群聊是否需 @

[trigger.command_descriptions]       # 可选：命令描述（帮助插件自动生成用）
"/cmd1"     = "命令1的功能说明"
"/cmd2"     = "命令2的功能说明"
```

### Python 主文件标准书写顺序

> **核心原则：从外到内、从抽象到具体、从声明到实现。**

```python
# ═══════════════════════════════════════════════════════════
# 第 1 层：模块文档
# ═══════════════════════════════════════════════════════════
"""我的插件 — 一句话描述功能

命令：
  /cmd1 <参数>   — 功能说明
  /cmd2          — 功能说明
"""

# ═══════════════════════════════════════════════════════════
# 第 2 层：标准库导入
# ═══════════════════════════════════════════════════════════
import os
import time
from typing import Optional

# ═══════════════════════════════════════════════════════════
# 第 3 层：第三方库导入
# ═══════════════════════════════════════════════════════════
import httpx

# ═══════════════════════════════════════════════════════════
# 第 4 层：框架公共 API 导入（统一从 graci 导入）
# ═══════════════════════════════════════════════════════════
from graci import on_command, plugin_handler, PluginContext, get_logger
from graci import GracyText, GracyImage, GracyVoice
from graci import plugin_manager, logger as _framework_logger
from graci import (
    get_current_master_id,    # 多账号：获取主人 ID
    get_current_robot_id,     # 多账号：获取当前机器人 ID
    require_master,           # 装饰器：主人权限
    rate_limit,               # 装饰器：频率限制
    cooldown,                 # 装饰器：冷却
)

# ═══════════════════════════════════════════════════════════
# 第 5 层：插件自身模块导入
# ═══════════════════════════════════════════════════════════
from .core.api import search_songs
from .core.draw import draw_results
from .config import load_config

# ═══════════════════════════════════════════════════════════
# 第 6 层：日志器（独立于框架日志）
# ═══════════════════════════════════════════════════════════
logger = get_logger("我的插件")

# ═══════════════════════════════════════════════════════════
# 第 7 层：常量定义
# ═══════════════════════════════════════════════════════════
PLUGIN_DIR = os.path.dirname(os.path.abspath(__file__))
DATA_DIR = os.path.join(PLUGIN_DIR, "data")
CACHE_DIR = os.path.join(DATA_DIR, "cache")
CACHE_MAX_DAYS = 7

# ═══════════════════════════════════════════════════════════
# 第 8 层：模块级状态（可选，跨调用保持状态）
# ═══════════════════════════════════════════════════════════
_last_search_results: list = []
_config_cache: Optional[dict] = None

# ═══════════════════════════════════════════════════════════
# 第 9 层：辅助函数（私有，以下划线开头）
# ═══════════════════════════════════════════════════════════
def _get_config() -> dict:
    global _config_cache
    if _config_cache is None:
        _config_cache = load_config()
    return _config_cache


async def _download_file(url: str, filename: str) -> Optional[str]:
    """下载文件到缓存目录，返回本地路径"""
    os.makedirs(CACHE_DIR, exist_ok=True)
    local_path = os.path.join(CACHE_DIR, filename)
    try:
        async with httpx.AsyncClient(timeout=30) as client:
            resp = await client.get(url)
            resp.raise_for_status()
            with open(local_path, "wb") as f:
                f.write(resp.content)
        return local_path
    except Exception as e:
        logger.error(f"下载失败: {e}")
        return None


# ═══════════════════════════════════════════════════════════
# 第 10 层：装饰器注册 + Handler 函数
# ═══════════════════════════════════════════════════════════

# ── 简单场景：单命令 ──
@on_command("/cmd1")
@plugin_handler
async def handle_cmd1(ctx: PluginContext):
    """处理 /cmd1 命令"""
    await ctx.reply("Hello!")


# ── 多命令 + 参数解析 ──
@on_command("/cmd2", "/cmd2_alias")
@plugin_handler
async def handle_cmd2(ctx: PluginContext):
    """处理 /cmd2 命令，支持参数"""
    args = ctx.raw_text[len(ctx.command):].strip()
    if not args:
        await ctx.reply("用法：/cmd2 <参数>")
        return
    await ctx.reply(f"你输入了：{args}")


# ── 权限控制 ──
@on_command("/admin")
@require_master
@plugin_handler
async def handle_admin(ctx: PluginContext):
    """仅主人可用的管理命令"""
    await ctx.reply("管理员命令执行成功")


# ── 频率限制 ──
@on_command("/search")
@rate_limit(max_calls=5, period=60)
@plugin_handler
async def handle_search(ctx: PluginContext):
    """搜索命令，60秒内最多5次"""
    args = ctx.raw_text[len(ctx.command):].strip()
    await ctx.reply(f"搜索：{args}")


# ── 冷却 ──
@on_command("/status")
@cooldown(seconds=3)
@plugin_handler
async def handle_status(ctx: PluginContext):
    """状态查询，3秒冷却"""
    await ctx.reply("系统正常")


# ── 发送图片 ──
@on_command("/draw")
@plugin_handler
async def handle_draw(ctx: PluginContext):
    """生成图片并发送"""
    img_path = draw_results()
    await ctx.send(GracyImage(file_path=img_path))


# ── 发送语音 ──
@on_command("/voice")
@plugin_handler
async def handle_voice(ctx: PluginContext):
    """下载音频并发送语音"""
    local_path = await _download_file("https://example.com/audio.mp3", "audio.mp3")
    if local_path:
        await ctx.send(GracyVoice(file_path=local_path))
    else:
        await ctx.reply("下载失败")


# ── 兜底处理（接住所有未匹配消息） ──
from graci import on_fallback

@on_fallback()
@plugin_handler
async def handle_fallback(ctx: PluginContext):
    """处理所有未匹配的消息（如 AI 对话）"""
    await ctx.reply(f"我不理解：{ctx.raw_text}")
```

### 配置文件模式（如需读取 JSON 配置）

> 插件配置统一放在 `res/config/` 目录下，格式为 JSON。
> 插件内部通过 `plugin_manager.get_plugin_config()` 读取。

```
res/config/
├── MyPlugin_config.json       # 插件配置文件（命名：目录名 + _config.json）
├── Music_Plugin_config.json
└── LLM_Chat_config.json
```

config.py 模板：

```python
"""配置读取辅助"""
import os
import json
from graci import plugin_manager

_CONFIG_CACHE = None

def load_config() -> dict:
    """读取插件配置（带缓存）"""
    global _CONFIG_CACHE
    if _CONFIG_CACHE is not None:
        return _CONFIG_CACHE
    _CONFIG_CACHE = plugin_manager.get_plugin_config("MyPlugin") or {}
    return _CONFIG_CACHE

def reload_config() -> dict:
    """强制重新加载配置"""
    global _CONFIG_CACHE
    _CONFIG_CACHE = None
    return load_config()
```

### Handler 签名规范

| 风格 | 签名 | 适用场景 |
|------|------|----------|
| **新风格（推荐）** | `async def handler(ctx: PluginContext)` | 所有新插件 |
| 旧风格（兼容） | `async def handler(self_bot, bot, message, user_id, chat_type, permission, log_func)` | 旧插件迁移前 |

> Pipeline 通过 `len(params)` 自动判断：`> 1` 走旧式，`== 1` 走新式。
> 新风格插件无需关心框架内部实现，只用 `ctx` 即可。

### 装饰器叠加顺序

> 装饰器从上到下执行，`@on_command` 在最外层，`@plugin_handler` 在最内层。

```python
@on_command("/cmd")        # 1. 命令匹配（最外层）
@require_master            # 2. 权限校验
@rate_limit(max_calls=3)   # 3. 频率限制
@cooldown(seconds=5)       # 4. 冷却检查
@plugin_handler            # 5. 核心包装（最内层，注入 ctx）
async def handle_cmd(ctx: PluginContext):
    ...
```

### 完整实际示例：音乐插件

> 以 `Music_Plugin` 为参考，展示多命令、状态管理、图片/语音发送的完整模式。

```python
"""音乐点歌插件 — 搜索 + 播放

命令：
  /点歌 <关键词>     — 搜索歌曲
  /选择 <编号>       — 选中并下载播放
  /歌曲详情          — 查看详情
  /清理缓存          — 清理过期缓存
"""
import os
import time
from typing import Optional

import httpx

from graci import plugin_manager

from .core.api import search_songs, play_song
from .core.draw import draw_search_results

logger = get_logger("Music")

# ── 状态 ──
_last_search_results: list = []

DATA_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "data")


@on_command("/点歌", "/qq音乐")
@plugin_handler
async def handle_search(ctx: PluginContext):
    """搜索歌曲"""
    args = ctx.raw_text[len(ctx.command):].strip()
    if not args:
        await ctx.reply("用法：/点歌 <歌曲名>")
        return

    await ctx.reply(f"🔍 正在搜索: {args}")
    results, _ = await search_songs(args)

    if not results:
        await ctx.reply(f"没有找到「{args}」的歌曲")
        return

    _last_search_results = results[:10]
    img_path = draw_search_results(_last_search_results, args)
    await ctx.send(GracyImage(file_path=img_path))


@on_command("/选择")
@plugin_handler
async def handle_select(ctx: PluginContext):
    """选择并播放"""
    if not _last_search_results:
        await ctx.reply("请先用 /点歌 搜索")
        return

    args = ctx.raw_text[len(ctx.command):].strip()
    if not args or not args.isdigit():
        await ctx.reply("用法：/选择 <编号>")
        return

    idx = int(args) - 1
    if idx < 0 or idx >= len(_last_search_results):
        await ctx.reply(f"编号超出范围（1-{len(_last_search_results)}）")
        return

    selected = _last_search_results[idx]
    detail = await play_song(selected.keyword, selected.idx)
    if detail and detail.music_url:
        local = await _download_mp3(detail.music_url, detail.name)
        if local:
            await ctx.send(GracyVoice(file_path=local))
            return

    await ctx.reply(f"🎵 {selected.name} — {selected.artist}")


@on_command("/清理缓存")
@plugin_handler
async def handle_clean(ctx: PluginContext):
    """清理过期缓存"""
    cache_dir = os.path.join(DATA_DIR, "cache")
    if not os.path.isdir(cache_dir):
        await ctx.reply("缓存目录不存在")
        return

    now = time.time()
    deleted = 0
    for f in os.listdir(cache_dir):
        fp = os.path.join(cache_dir, f)
        if os.path.isfile(fp) and now - os.path.getmtime(fp) > 7 * 86400:
            os.remove(fp)
            deleted += 1

    await ctx.reply(f"清理完成，删除 {deleted} 个过期文件")
```
